# 新建表单交互示意原型

## 项目说明

项目名称：新建表单交互示意原型

项目说明：用于演示从表单列表中新建表单、配置字段、自动生成布局预览的交互流程

## 使用方式

1. 打开 `index.html` 本地预览
2. 或部署到 GitHub Pages 后通过网页访问

## GitHub Pages 发布说明

1. 将 `index.html`、`README.md`、`assets` 文件夹提交到仓库
2. 打开仓库 Settings
3. 进入 Pages
4. Source 选择 Deploy from a branch
5. Branch 选择 main / root
6. 保存后等待生成访问地址
